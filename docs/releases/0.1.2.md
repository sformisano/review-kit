# Review Kit 0.1.2

Review Kit 0.1.2 corrects the recovery hints that `rkc` prints and the documentation.
Commands, configuration, diagnostic codes, exit statuses, retained-state formats, schemas and the embedded rendering profile are unchanged from 0.1.1.
The [0.1.1 release notes](0.1.1.md) describe the summary layout, the conversation check before publication and the note author accounts.
Use the [build identity](../distribution.md#build-identity) to identify the exact executable.

## Recovery hints

Hints that told a refused run to start over with `rkc run start --new` now name the route that fits the run.
A run without a publication binding is stopped first with `rkc run stop --reason TEXT`, and `rkc run start` then starts the new run.
After `rkc publish --abandon` the run is settled, so the hint names plain `rkc run start`.
Only a run whose publication binding sent nothing keeps `rkc run start --new`.
That run cannot be stopped until the new run's publication releases its binding.

The changed hints include those after `source_changed`, `conversation_changed` and `uncompared_write` refusals and after a revision change during publication.
Others name the way past another run's unfinished publication, a missing publication journal, and damaged retained files or accepted assessment.
The [publication reference](../../crates/bin/cli/README.md#publication-and-recovery) describes both routes.

## Documentation corrections

- The [captured conversation reference](../../crates/bin/cli/README.md#captured-conversation) names every 0.1.0 command that fails on a run started by 0.1.1 or later, including `run select`, with its code.
- The [publication reference](../../crates/bin/cli/README.md#publication-and-recovery) defines the write targets and lists in a table which changes block publication.
- The [exit status table](../../crates/bin/cli/README.md#output-and-exit-status) lists codes that the CLI reports but the table omitted, such as `unsupported_version`.
- The READMEs, the feature contract, the decisions and the distribution guide state the 0.1.1 behavior in plain, accurate sentences.

## Upgrade and rollback

0.1.2 reads and writes the same formats as 0.1.1 and embeds the same rendering profile.
An unfinished round that 0.1.1 started therefore continues with 0.1.2, and the reverse.
Switch between 0.1.1 and 0.1.2 with the [upgrade and rollback](../distribution.md#upgrade-and-rollback) procedure.
To upgrade from 0.1.0, follow the [0.1.1 upgrade and rollback notes](0.1.1.md#upgrade-and-rollback).
`rkc --version` returns `rkc 0.1.2`.

## Verification and limits

The [distribution gates](../distribution.md#distribution-gates) define the source, package and download checks for this release.
Runtime checks cover Rocky Linux 9, Ubuntu 24.04 LTS and Ubuntu 26.04.1 LTS on x86_64.
Provider checks use the pinned local GitLab CE server and disposable merge requests.
The [0.1.0 scope and limits](0.1.0.md#scope-and-limits) apply unchanged.
