# Repository instructions

Start with [README.md](README.md) and the [documentation index](docs/README.md).
Read [decisions](docs/decisions.md) before changing scope.

- Keep proposals, accepted decisions and implemented behavior distinct.
- Use [features](docs/features.md) for the product contract, [plan](docs/plan.md) for status and [workflow](docs/workflow.md) for compatibility boundaries.
- Read the relevant crate README before changing its types, use cases or adapter guarantees; the [architecture](docs/architecture.md) maps components.
- Read the [CLI guide](crates/bin/cli/README.md) before changing commands, configuration or workspace files.
- Before changing source, install the declared skills and follow [agent skills](docs/agent-skills.md).
- Keep credentials, private provider identifiers, raw prompts and local execution evidence outside tracked project documents.
